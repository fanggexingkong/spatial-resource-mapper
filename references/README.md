# references

本目录存放空间资源地图工具的方法论文档、案例说明和口径参考。

## 当前文档

| 文档 | 说明 |
|---|---|
| `shandong-case-study.md` | 山东文化资源地图项目案例，包含点位口径、资源分类、地市分布、清洗规则和一致性校验结果 |
| `methodology.md` | 通用数据整合方法论，包括汇聚清洗、坐标精修、空间归属、多级切分、多格式导出、一致性校验和资产化归档 |
| `classification-example.md` | 资源分类体系示例，用于说明如何定义和替换分类口径 |
| `cleaning-rules.md` | 通用清洗规则与项目特定清洗规则的说明 |

## 使用建议

- `methodology.md` 适合作为通用流程说明；
- `shandong-case-study.md` 适合作为方法验证案例；
- `classification-example.md` 和 `cleaning-rules.md` 适合在迁移到其他省份或领域时作为口径参考；
- 所有案例文档中的区域范围、分类体系和字段口径都不应直接视为默认规则。
