# 空间资源数据整合方法论

本文档记录了空间资源地图项目的通用数据整合方法论，适用于任意省份、任意领域的资源点位数据治理。

## 总体流程

```
汇聚清洗 -> 坐标精修 -> 空间归属 -> 多级切分 -> 多格式导出 -> 一致性校验 -> 资产化归档
```

## 第一阶段：汇聚清洗

### 目标

将多源、多格式、多坐标系的数据汇聚到统一的数据池中，完成初步清洗。

### 关键动作

- 统一字段命名规范：名称、地址、经度、纬度、坐标系、类型、行政区、区县、来源
- 去除重复点位（按名称+坐标双重去重）
- 去除无效坐标（空值、非数值、超出经纬度范围、0,0 坐标）
- 去除明显越界坐标（如落在海域、明显不属于目标区域的坐标）
- 标准化地址文本（统一省市区名称、去除多余空格和标点）
- 标准化类型名称（如"文保单位"和"文物保护单位"统一）

### 可替换参数

- 目标区域范围（省/市/区县）
- 资源类型定义（文化/生态/基建等）
- 坐标系要求（WGS84/GCJ02/BD09）
- 字段命名规范（可根据目标系统调整）

### 输出物

- 清洗后数据表（含原始字段和清洗后字段）
- 清洗日志（记录被剔除的数据及原因）

## 第二阶段：坐标精修

### 目标

对坐标进行校验和补全，确保每个有效点位都有可用的坐标信息。

### 关键动作

- 优先保留权威来源坐标（如政府公开数据、测绘数据）
- 对缺失坐标的点位，按地址进行地理编码补全
- 对通过名称线索推断的坐标，标记为低置信度
- 统一坐标系口径（建议入库前统一为 WGS84）
- 对坐标精度进行评估（精确到门牌号 / 街道 / 区县 / 地市）

### 可替换参数

- 地理编码服务来源（高德/百度/腾讯/OSM）
- 坐标精度评估标准
- 坐标系转换规则

### 输出物

- 坐标精修后数据表
- 坐标置信度标签（高/中/低/待核验）

## 第三阶段：空间归属

### 目标

为每个点位确定其所属的行政区划归属。

### 关键动作

- 使用行政区划边界文件进行空间叠加（point-in-polygon）
- 对无坐标点位，通过地址地理编码后再次做空间归属
- 对编码失败或低置信数据，进入人工核验流程
- 对跨边界点位，使用权威行政区划边界复核
- 记录归属推断方法和置信度

### 可替换参数

- 行政区划边界文件（需使用者自备）
- 行政区层级（地市/区县/乡镇）
- 归属置信度阈值

### 输出物

- 带行政区归属的数据表
- 未识别/待核验点位清单

## 第四阶段：多级切分

### 目标

按不同维度对数据进行切分和统计。

### 关键动作

- 按资源类型切分统计
- 按行政区切分统计
- 按数据来源切分统计
- 按时间维度切分（如有时间字段）
- 交叉校验各维度合计是否一致

### 可替换参数

- 切分维度（可根据业务需求自定义）
- 统计粒度（省/市/区县/乡镇）

### 输出物

- 分类统计表
- 行政区分布表
- 交叉校验报告

## 第五阶段：多格式导出

### 目标

根据不同使用场景，导出为不同格式的数据文件。

### 关键动作

- GeoJSON：用于地图展示和 GIS 分析
- CSV/Excel：用于资料库入库和数据透视
- Markdown/PDF：用于项目总结和汇报
- 导出时保留元数据（坐标系、置信度、推断方法等）

### 可替换参数

- 导出格式（根据目标系统支持情况选择）
- 字段选择（根据下游系统要求裁剪）

### 输出物

- GeoJSON 文件
- CSV/Excel 文件
- 项目总结报告

## 第六阶段：一致性校验

### 目标

确保数据质量和逻辑一致性。

### 校验规则

- 总数校验：分类合计 = 行政区合计 = 总点位数量
- 坐标校验：经纬度范围合法、坐标系一致
- 字段完整性校验：必要字段无空值
- 轨迹校验：每条推断数据都有推断方法和置信度
- 重复性校验：无重复点位

### 输出物

- 数据质量报告
- 异常数据清单

## 第七阶段：资产化归档

### 目标

将清洗后的数据和方法论沉淀为可复用的资产。

### 关键动作

- 数据资产归档（标准数据表 + 元数据说明）
- 方法论文档化（本文档 + 项目案例）
- 脚本工具化（可复用的数据处理脚本）
- 版本管理（记录数据版本和更新日志）

### 输出物

- 标准数据集
- 方法论文档
- 可复用脚本
- 版本变更记录

## 迁移指南

当将本方法论迁移到其他省份或其他领域时，需要重点关注以下可替换参数：

| 可替换项 | 说明 | 示例 |
|---|---|---|
| 区域范围 | 目标省份/市/区县 | 山东省 -> 河南省 |
| 行政区划边界 | 对应的边界文件 | 山东边界 -> 河南边界 |
| 资源分类体系 | 根据领域重新定义 | 文化资源 -> 生态资源 |
| 坐标系口径 | 根据数据源调整 | WGS84 -> CGCS2000 |
| 数据来源 | 根据实际数据源调整 | 文化厅数据 -> 林业局数据 |
| 置信度阈值 | 根据数据质量调整 | 高>0.9 -> 高>0.95 |
| 统计维度 | 根据业务需求调整 | 按类型+地市 -> 按类型+区县 |
| 字段定义 | 根据下游系统调整 | 增加/减少字段 |
