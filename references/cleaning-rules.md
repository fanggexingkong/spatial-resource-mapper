# 数据清洗规则

本文档定义了空间资源地图项目的数据清洗规则，分为通用规则和项目补充规则两部分。
通用规则适用于所有项目，项目补充规则仅适用于特定项目（如山东文化资源地图项目）。

## 通用清洗规则

### 1. 坐标有效性校验

#### 规则 1.1：空值检查
- 条件：经度或纬度为空（NULL/None/空字符串）
- 处理：标记为"坐标缺失"，进入坐标补全流程或标记为待核验
- 置信度：待核验

#### 规则 1.2：数值类型检查
- 条件：经度或纬度无法转换为数值类型
- 处理：标记为"坐标格式异常"，排除出正式库
- 置信度：无效

#### 规则 1.3：经纬度范围检查
- 条件：纬度不在 [-90, 90] 范围内，或经度不在 [-180, 180] 范围内
- 处理：标记为"坐标越界"，排除出正式库
- 置信度：无效

#### 规则 1.4：零坐标检查
- 条件：经度=0 且 纬度=0
- 处理：标记为"零坐标"，排除出正式库
- 置信度：无效
- 说明：(0,0) 通常是地理编码失败的默认返回值，不代表真实位置

#### 规则 1.5：海域坐标检查
- 条件：坐标落在目标区域周边的海域范围内
- 处理：标记为"海域坐标"，排除出正式库或单独归类
- 置信度：低
- 说明：需要配备海域边界数据才能执行此规则

### 2. 重复性检查

#### 规则 2.1：完全重复检查
- 条件：名称+经度+纬度完全相同的记录
- 处理：保留第一条，其余标记为"重复记录"并剔除
- 置信度：高（保留的那条）

#### 规则 2.2：坐标重复检查
- 条件：经度+纬度相同但名称不同的记录
- 处理：保留名称最完整的一条，其余标记为"坐标重复-名称不同"
- 置信度：中
- 说明：可能是同一地点的不同名称，需人工确认

#### 规则 2.3：名称重复检查
- 条件：名称相同但坐标不同的记录
- 处理：按多点位处理，不自动合并
- 置信度：中
- 说明：可能是同名不同址，需根据地址等其他字段判断

### 3. 地址标准化

#### 规则 3.1：省名标准化
- 示例："山东省"、"山东"、"鲁" -> 统一为"山东省"
- 处理：建立省名映射表，批量替换

#### 规则 3.2：市名标准化
- 示例："济南市"、"济南" -> 统一为"济南市"
- 处理：建立市名映射表，批量替换

#### 规则 3.3：区县名标准化
- 示例："历下区"、"历下" -> 统一为"历下区"
- 处理：建立区县名映射表，批量替换

#### 规则 3.4：地址格式统一
- 去除多余空格、特殊字符
- 统一标点符号（全角/半角）
- 统一路径表述（"XX路" vs "XX路段"）

### 4. 类型名称标准化

#### 规则 4.1：同义词统一
- 示例："文保单位" -> "文物保护单位"
- 示例："博物馆" -> "博物馆"
- 处理：建立类型名称映射表，批量替换

#### 规则 4.2：分级名称统一
- 示例："全国重点文物保护单位"、"国保" -> "全国重点文物保护单位"
- 示例："省级文物保护单位"、"省保" -> "省级文物保护单位"
- 处理：建立分级名称映射表，批量替换

### 5. 行政区划名称标准化

#### 规则 5.1：最新区划名称映射
- 说明：行政区划可能因调整而变更名称或隶属关系
- 处理：使用最新行政区划代码表进行映射
- 特别注意：撤县设区、撤市设区、合并拆分等情况

#### 规则 5.2：异常区划名称处理
- 条件：区划名称不在标准区划名称表中
- 处理：标记为"区划名称异常"，进入人工核验
- 常见原因：简称、旧称、错别字

## 项目补充规则

> 以下规则仅适用于山东文化资源地图项目，迁移到其他项目时请根据实际需求调整或删除。

### 山东特有规则

#### 规则 S1：莱芜行政区划处理
- 背景：2019年莱芜市撤销，辖区划归济南市
- 处理：原"莱芜市"相关点位归属调整为"济南市"
- 置信度：高（有明确政策依据）

#### 规则 S2：山东地市名称映射
- 山东 16 地市名称可能存在简称写法，需统一映射
- 示例："烟台" -> "烟台市"、"威海" -> "威海市"
- 处理：建立山东 16 地市专用映射表

#### 规则 S3：文保单位地址残缺处理
- 背景：部分文保单位地址信息不完整
- 处理：优先使用坐标空间归属判断地市/区县
- 辅助手段：名称中包含的地市线索可作为辅助参考
- 置信度：中（需结合多种线索综合判断）

#### 规则 S4：非遗场所名称规范化
- 背景：非遗项目名称可能存在多种写法
- 处理：参考山东省非遗名录官方名称进行标准化
- 置信度：高（有官方名录可对照）

## 清洗轨迹记录规范

每条数据的清洗过程应记录以下信息：

| 字段 | 说明 | 示例 |
|---|---|---|
| 原始值 | 清洗前的原始数据 | "济南" |
| 清洗后值 | 清洗后的标准值 | "济南市" |
| 清洗规则 | 应用的清洗规则编号 | "规则 3.2" |
| 清洗方法 | 清洗方法描述 | "市名映射表替换" |
| 置信度 | 清洗结果置信度 | "高" |
| 操作时间 | 清洗执行时间 | "2026-10-29 10:00:00" |
| 操作人 | 执行清洗的人员或系统 | "auto-cleaning-v1.0" |

## 清洗质量评估指标

| 指标 | 计算方式 | 目标值 |
|---|---|---|
| 坐标有效率 | 有效坐标记录数 / 总记录数 | >= 95% |
| 坐标高置信率 | 高置信坐标记录数 / 有效坐标记录数 | >= 80% |
| 行政区识别率 | 已识别行政区记录数 / 总记录数 | >= 90% |
| 重复记录率 | 重复记录数 / 总记录数 | <= 2% |
| 字段完整率 | 关键字段非空记录数 / 总记录数 | >= 98% |
