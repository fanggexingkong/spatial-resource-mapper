# 资源分类体系示例

本文档以山东文化资源地图项目为例，展示资源分类体系的设计方法和替换指南。
迁移到其他省份或领域时，请参考"分类体系替换指南"部分重新定义分类口径。

## 山东文化资源分类体系

### 一级分类

| 分类代码 | 分类名称 | 说明 |
|---|---|---|
| A | 文物保护单位 | 各级文物保护单位（全国/省/市/县级） |
| B | 非物质文化遗产 | 非遗项目相关场所和载体 |
| C | 博物馆 | 各类博物馆、纪念馆 |
| D | 公园与绿地 | 城市公园、植物园、动物园等 |
| E | 旅游景区 | A级景区、风景名胜区 |
| F | 文化场馆 | 文化馆、图书馆、档案馆、剧院等 |
| G | 历史文化名城名镇名村 | 历史文化街区、传统村落 |
| H | 其他文化资源 | 不符合以上分类的文化相关资源 |

### 二级分类示例

#### A. 文物保护单位

| 代码 | 名称 | 说明 |
|---|---|---|
| A01 | 全国重点文物保护单位 | 国务院公布 |
| A02 | 省级文物保护单位 | 省政府公布 |
| A03 | 市级文物保护单位 | 市政府公布 |
| A04 | 县级文物保护单位 | 县政府公布 |

#### C. 博物馆

| 代码 | 名称 | 说明 |
|---|---|---|
| C01 | 综合博物馆 | 综合性历史博物馆 |
| C02 | 专题博物馆 | 专题性博物馆（如民俗、自然等） |
| C03 | 纪念馆 | 纪念人物或事件 |
| C04 | 行业博物馆 | 行业系统主办的博物馆 |

### 分类编码规则

1. 一级分类用大写英文字母（A-Z），最多支持 26 个一级分类
2. 二级分类用一级代码+两位数字（如 A01、A02）
3. 三级分类可扩展为三级代码+两位数字（如 A0101）
4. 编码应保持稳定，避免频繁调整

## 分类命名规范

### 命名原则

- 使用中文通用名称，避免生僻字和专业术语
- 名称应简洁明确，一看即知资源类型
- 同义名称应统一（如"文保单位"统一为"文物保护单位"）
- 新增分类时应遵循已有分类的命名风格

### 命名示例

| 不规范命名 | 规范命名 | 说明 |
|---|---|---|
| 文保单位 | 文物保护单位 | 全称更规范 |
| 博物馆/纪念馆 | 博物馆 | 合并为一级分类 |
| 公园/绿地 | 公园与绿地 | 合并同类 |
| 4A景区 | 旅游景区 | 不区分等级，等级另设字段 |

## 分类体系替换指南

当将分类体系迁移到其他省份或其他领域时，按以下步骤操作：

### 步骤一：梳理目标领域资源类型

1. 调研目标领域的资源类型有哪些
2. 参考国家标准或行业标准（如文物分类标准、旅游分类标准）
3. 列出所有可能的资源类型

### 步骤二：设计一级分类

1. 将资源类型归纳为 5-10 个一级类别
2. 确保分类之间互不重叠、覆盖全面
3. 预留"其他"类别用于容纳特殊情况

### 步骤三：设计二级分类（可选）

1. 对一级分类下细分较多的类别，设计二级分类
2. 二级分类不宜过细，一般 3-5 个子类即可
3. 避免三级以上分类，保持简洁

### 步骤四：映射现有数据

1. 将历史数据中的类型名称映射到新分类体系
2. 建立映射表，记录原始名称到新代码的对应关系
3. 对无法映射的数据标记为"待确认"

### 步骤五：验证分类体系

1. 用实际数据验证分类覆盖率
2. 检查是否有大量数据落入"其他"类别（超过 10% 需调整）
3. 征求领域专家意见
