# 山东文化资源地图项目案例

本文档记录山东文化资源地图项目的数据整合实践，仅作为 `spatial-resource-mapper` 的方法验证案例。
迁移到其他省份或其他领域时，需要替换区域范围、分类体系、边界数据和字段口径。

## 项目背景

该项目面向山东省文化资源地图与资料库建设，主要工作包括多源文化资源数据汇聚、坐标精修、
空间归属判断、分类统计、多格式导出和一致性校验。

目标是将分散在不同来源的文化资源点位整理成统一口径的标准数据集，支撑地图展示、资料库入库
和后续跨地区复用。

## 数据范围

- 区域范围：山东省
- 行政区层级：地市、区县
- 资源类型：文化资源点位，示例包括文保单位、非遗场所、博物馆、公园、景区、文化场馆等
- 点位总量：8786 条
- 坐标系：统一采用 WGS84 或 GCJ02 口径，需在入库前明确来源坐标系

## 字段口径

建议保留以下字段：

| 字段 | 说明 |
|---|---|
| 名称 | 资源点位名称 |
| 地址 | 原始地址文本 |
| 经度 | 点位经度 |
| 纬度 | 点位纬度 |
| 坐标系 | WGS84 / GCJ02 / BD09 等 |
| 类型 | 资源分类 |
| 地市 | 所属地市 |
| 区县 | 所属区县 |
| 来源 | 数据来源 |
| 置信度 | 高 / 中 / 低 / 待核验 |
| 推断方法 | 坐标空间归属 / 地址编码 / 名称推断 / 人工核验 |

## 清洗规则

### 通用规则

- 排除无效坐标：空值、非数值、超出经纬度范围
- 排除 `(0, 0)` 坐标
- 排除明显省外坐标
- 排除落在海域的坐标
- 标准化地址、类型名称和行政区划名称
- 保留原始字段，新增清洗后字段

### 山东项目补充规则

- 对"未识别地市"点位，优先使用坐标空间归属判断
- 对无坐标但地址完整点位，进入地理编码流程
- 对名称中包含明显地市线索的点位，可作为辅助判断依据，但不单独作为归属依据
- 莱芜相关点位需结合最新行政区划归属复核
- 文保单位、公园等类型容易出现地址残缺，需重点人工核验

## 空间归属方法

1. 使用山东地市行政区划边界对有效坐标进行空间叠加；
2. 对无坐标点位，先尝试地址地理编码；
3. 对编码结果再次用边界数据校验；
4. 对低置信数据标记为"待核验"，不自动并入正式库；
5. 对跨边界点位，使用权威行政区划边界复核。

## 分类统计口径

- 按资源类型统计分布；
- 按地市统计分布；
- 按来源统计分布；
- 输出分类分布表、地市分布表；
- 对分类合计、地市合计、总数进行交叉校验；
- 本项目点位总数为 8786，分类合计与地市合计均应与此一致。

## 一致性校验

- 总数校验：分类合计 = 地市合计 = 总点位数量；
- 坐标校验：经纬度范围、坐标系一致性；
- 字段校验：名称、类型、行政区、来源是否完整；
- 轨迹校验：每条推断数据都应保留推断方法和置信度；
- 异常清单：未识别、低置信、坐标异常数据单独输出。

## 输出成果

- 标准点位表：用于资料库入库；
- GeoJSON 文件：用于地图展示；
- 分类分布表：按资源类型统计；
- 地市分布表：按地市统计；
- 清洗轨迹表：记录原始值、推断值、推断方法、置信度；
- 问题清单：记录待核验和异常数据。

## 可迁移说明

本案例中的 8786 点位总量、山东 16 地市划分、文化资源分类体系均属于项目特定口径。
迁移到其他省份或领域时，应重点替换：

- 区域范围和行政区划边界；
- 资源分类体系；
- 坐标系口径；
- 数据来源和字段定义；
- 置信度阈值和人工核验规则；
- 统计维度和输出格式。
